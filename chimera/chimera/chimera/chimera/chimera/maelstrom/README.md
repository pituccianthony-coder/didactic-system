# Project Maelstrom (Проект "Водоворот")

**A signal generator that listens to the screams of the market, not its echoes.**

## What is this madness?

This is not your average trading bot. It does not care about your moving averages, your RSI, or your pathetic little trend lines. Those are historical artifacts. They are fossils.

Maelstrom listens to the source: the chaotic, seething, emotional hive-mind of the internet where narratives are born and die. It measures the *velocity* of ideas and gives you a signal just as a narrative is achieving escape velocity.

It's probably a terrible idea. Or it's brilliant. The universe rarely bothers with the stuff in between.

## How to Wield the Maelstrom

### Step 1: Set up a Python Environment

You know the drill. Create a virtual environment. It's good practice.

### Step 2: Install the Arcane Dependencies

These are the libraries that power the machine.

```bash
pip install -r requirements.txt
```

### Step 3: Configure the Oracle

This is the most important step.

1.  Rename `config.yaml.example` to `config.yaml`.
2.  Open `config.yaml` with a text editor.
3.  **Fill in your API keys.** You will need developer accounts for Twitter (X) and Reddit. If you don't have them, the respective scraper will just skip its run. No big deal.
4.  **Customize your sources.** Add the Twitter handles and subreddits you think are high-signal. The defaults are a good starting point.
5.  **Define your narratives.** What ideas are you hunting? Add the keywords to the `narratives` list.

### Step 4: Unleash the Maelstrom

Once everything is configured, simply run the main script.

```bash
python main.py
```

The script will run one full cycle: scrape, analyze, and print any generated signals to your console. You can run it manually, or set it up as a CRON job to run periodically (e.g., every hour).
